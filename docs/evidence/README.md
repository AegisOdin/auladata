# Evidencias de AulaData

Esta carpeta conserva capturas reales del navegador y resultados de verificaciones.
Cada evidencia debe indicar qué se ejecutó y el ambiente usado. Las pruebas locales
no acreditan un despliegue, aprobación de QA, migración live o HA en Proxmox.

No guardar contraseñas, cookies, tokens ni archivos de configuración privados.
El inventario y los resultados se completan conforme se valida el proyecto.
